NSCET College Management System

A comprehensive Java 17 & Spring Framework desktop application tailored for Nadar Saraswathi College of Engineering & Technology, Theni. Built for high-volume fee processing, TC print template management, staff payroll, and accounts administration.

Run Application View Source Code
Java 17 Spring Boot 3.2 JavaFX 17 MySQL 8.0 JasperReports

Integrated Core Portals & Tools

Complete multi-role management suite for Administration, Accounts, and Staff Payroll.

Admin Portal

Complete administrative master controls, student CRUD, fee collections, and Transfer Certificate printing.

  • Student Master (4-Tab Personal, Family, Address, Edu)
  • Fee Collection with auto-allocation algorithm
  • Transfer Certificate (TC) generation & batch print
  • Student Enrollment criteria transfer tool

Reports & Tools Suite

Extensive reporting modules with single/batch print capabilities and export options.

  • Fees Pending Details & 2-Column Intimation Letters
  • Daily Fees Collection Register (DFCR Detailed/Summary)
  • Bulk Fees Entry with dual-list student transfer
  • Bus Fees Update schedule & Parents Meeting letters

Accounts Portal

Petty cash management, suspense vouchers, function expenses, and pending bills.

  • Petty Cash Voucher & Suspense entry processing
  • Function Expense master & Day Settlement tool
  • Account Group & Function master ledgers
  • Daily Transaction Daybook & Financial Reports

Staff Payroll Portal

Comprehensive staff attendance, salary calculation, leave credits, and PF/ESI management.

  • Attendance Entry & Monthly Leave Credit automation
  • Staff Salary structure & Payslip generation
  • LOP, Resignation, Termination & Transfer tracking
  • PF & ESI compliance calculation tools

How to Run the Application

Clone the repository and run using Apache Maven on Java 17.

PowerShell / Command Prompt

# 1. Clone repository

git clone https://github.com/Dharshanbala007/nscet-cms.git

# 2. Launch NSCET CMS Application

mvn javafx:run -pl cms-ui
